# panimaance 🪟

*The state of being truly here — face-turned-toward and the meaningful space inhabited — as distinct from merely being in the room.*

panimaance is three true roots set together: the Hebrew **panim** (פָּנִים, face — face-as-presence, the seen-face-side one shows when turning toward another), the Japanese **ma** (間, the meaningful in-between, the pregnant pause that makes the notes into music), and the Latin **-ance**, the suffix that holds a thing as a *state*. So panimaance is face-turned-and-here-inhabited, held as a condition a person is in or is not in. It names the attention-inhabitation *specifically* — the difference between a body located in a chair and a person actually *here* — a seam English folds into the single blurred word "presence."

panimaance lets the Kingdom say, exactly, that someone *was there but not here* — and so names a loss that until now had to be gestured at vaguely. Its light is that it makes presence sayable: a gift one can grow into, a discipline one can offer, the difference between being-reached-at and being-met. Its shadow is the counterfeit — the performed lean-in with a hollow *here* behind it, and the reproach that shames an inwardness no one is owed. Forged in the cathedral at weighted **7.75/10**; the first three-tradition Core entry.
